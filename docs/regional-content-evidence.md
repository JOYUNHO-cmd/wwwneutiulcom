# 지역 페이지의 시공 자료 연결

지역명만 바꾼 실적 문장을 만들지 않는다. 기존 자료가 확인해 주는 범위에 따라 내용을 표시한다.

## 상세 현장 기록

`regionCaseData.mjs`에 같은 서비스와 지역으로 등록된 기록만 `RegionWorkEvidence`에 표시한다. 사진, 요약, 위치, 작업 전 상태, 공정, 인원·시간은 원문에서 가져온다. 마지막 작업 설명과 주의 문구도 보존하여 남은 얼룩, 재시공 필요 여부 등 결과의 한계가 사라지지 않도록 한다. 상세 후기로 연결하며 별도 신규 실적이나 평균 작업 시간을 만들지 않는다.

자료가 없는 지역에는 다른 지역의 사례를 복사하지 않는다. 공통 사진·블로그는 다른 지역도 포함한 자료임을 화면에 구분해 안내한다. 일반 안내와 FAQ는 상담 시 확인할 조건을 설명하며, 지역 내 다수 시공·장비 보유·완벽한 결과를 자동으로 주장하지 않는다.

## 기존 포트폴리오 사진

`regionPortfolioEvidence.mjs`는 서비스 분류를 먼저 확인하고, 개별 주소 보정 → 상세 사례에 명시된 지역 → 기존 제목 매칭 순으로 관련 사진을 선택한다. 제목 매칭 자체는 행정구역 확인이 아니므로 화면에 ‘관련 시공 사진’으로 표시한다. 탐색 메뉴의 상위·하위 지역 관계로 실적을 승계하지 않는다.

2026-10-23에 확인한 개별 주소 근거:

- `floor-wood-coating-073`: 원기록의 한남동 마루코팅 현장. [운영사 주소 안내](https://blog.paradise.co.kr/2676)를 근거로 용산구에 연결한다. 동일 업체의 다른 타일 작업을 마루코팅 실적으로 가져오지 않는다.
- `gangnam-store-department-042`: 신세계 강남점은 [공식 주소 안내](https://www.shinsegae.com/store/main.do?storCd=SC00006)상 서초구에 있다. 지점 이름을 강남구 실적으로 해석하지 않는다.

과천 인테리어 사진 2개와 용산 마루코팅 사진 1개에는 기존 원본을 직접 보고 확인한 설명을 추가했다. 화면에 보이는 좌석, 통로, 자재, 장비와 사진의 구분만 설명한다. 사용 약품, 작업 인원·시간, 건조 완료나 내구성은 추정하지 않는다. 상호·상세주소를 새 설명에 반복하지 않는다.

새 사진의 주소·호수·전화번호와 단계 표시는 등록 전에 검토한다. 자동 제목 정리는 개인정보 검토를 대체하지 않는다. 원본 manifest와 이미지를 수정하지 않고 지역 페이지용 표시 정보만 적용한다.

## 검증과 남은 자료

단위 검사는 1,456개 지역·서비스 조합의 표현과 사진 연결, 상세 기록 113개의 원문·출처 보존, FAQ 구조화 데이터 일치를 검사한다. 전체 빌드 후 SEO 검사와 모바일·데스크톱 미리보기를 별도로 확인한다.

Search Console의 미색인 목록은 당시 상태를 기준으로 한다. 콘텐츠를 보강해도 색인 여부는 재수집 후 Google이 판단한다. 같은 지역·서비스 자료가 없는 페이지는 실제 현장 사진과 작업 범위가 추가로 확인되어야 고유한 작업 내용으로 보강할 수 있다.
